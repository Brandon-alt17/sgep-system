# Imágenes para la guía de instalación

Coloque aquí las capturas de pantalla referenciadas en `docs/GUIA-INSTALACION-ENTREGA.md`.

Convención de nombres sugerida:

| Archivo | Contenido |
|---------|-----------|
| `01-contenido-usb.png` | Contenido de la memoria USB / carpeta del paquete |
| `02-wamp-instalador.png` | Instalación de WAMP |
| `03-wamp-icono-naranja-rojo.png` | Icono WAMP cuando faltan servicios |
| `04-wamp-icono-verde.png` | Icono WAMP con todos los servicios activos |
| `05-wamp-menu-servicios.png` | Menú WAMP → Apache / MySQL |
| `06-copiar-carpeta-www.png` | Copiar `sgep` a `C:\wamp64\www\` |
| `07-phpmyadmin-crear-bd.png` | Crear base de datos `sgep` en phpMyAdmin |
| `08-instalar-bat.png` | Ejecutar `instalar.bat` |
| `09-sgep-dashboard.png` | Pantalla principal del SGEP |
| `10-mamp-start.png` | MAMP con Apache y MySQL en verde |
| `11-mamp-httpd-rewrite.png` | `httpd.conf` con `mod_rewrite` activo |
| `12-mac-terminal-instalar.png` | Terminal ejecutando `bash instalar.sh` |
| `13-error-bash-cr.png` | (opcional) Error `bash\r` al copiar desde USB |

Formato recomendado: PNG, ancho máximo 1200 px.
